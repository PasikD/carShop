Приложение для покупки, аренды и обслуживания автомобиля с использованием базы данных Core Data

В приложении реализованы 3 направления с отдельным хранением данных. 
Реализована система пользователя и администратора, где администратор может добавлять, удалять данные и вносить в них изменения.
Реализована система фильтров.
Загрузка фотографий проихсдоит из памяти устройства.
Все файлы разделены по направлениям для удобства редактирования. 
На айфоне работает стабильно. В дальнейшем возможны доработки
